
# CodeAlpha Hangman Game

## Description
A simple word guessing game developed using Python.

## Features
- Five predefined words
- Random word selection
- Six maximum incorrect guesses
- Input validation
- Win and lose messages

## Technologies
- Python
- Python IDLE

## How to Run
1. Open main.py in Python IDLE.
2. Press F5.
3. Enter one letter at a time.

## Concepts Learned
- Loops
- Conditional statements
- Strings and lists
- Random module
